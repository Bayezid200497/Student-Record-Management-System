# Student-Record-Management-System
A C program for managing and sorting student records using six different sorting algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap Sort) built from scratch — with performance analysis (comparisons, swaps, execution time) across random, sorted, and reverse-sorted data, plus binary search and file save/load support.
Features — bullet list:
      Manual input / random data generation (size categories)
      6 sorting algorithms (Bubble, Selection, Insertion, Merge, Quick, Heap)
      Sort by ID or Marks, Ascending/Descending
     Iteration-by-iteration visualization
     Performance comparison (Random/Sorted/Reverse-sorted datasets)
     Comparison & swap counting, execution time measurement
     Binary Search
     Save/Load records to/from CSV file
Tech stack — Language: C (C11), no external libraries
